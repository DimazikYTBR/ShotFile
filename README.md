# ShotFile

**Скриншотнул — сохранил.**

ShotFile — небольшая программа для Windows 10 и 11. Она работает в фоне, и каждый скриншот, сделанный клавишами **Win + Shift + S**, сам сохраняется в нужную папку обычным файлом. Не нужно открывать Paint и вставлять картинку вручную.

## Возможности

- Автоматически сохраняет скриншоты в папку (по умолчанию `Загрузки\ShotFile`).
- Два режима: сохранять сразу или спрашивать перед каждым сохранением.
- Форматы PNG и JPG.
- Свой шаблон имени файла, например `Screenshot_2026-10-23_21-45-30`.
- Уведомление после сохранения с миниатюрой.
- Игровой режим: в полноэкранных играх скриншоты сохраняются молча, без окон и уведомлений.
- Переключатель в главном окне и пункт в меню трея ставят сохранение на паузу, не закрывая программу.
- Работает из трея, может запускаться вместе с Windows.

## Установка

1. Откройте страницу **Releases** этого репозитория и скачайте `ShotFile.exe`.
2. Запустите файл двойным щелчком. Установка не нужна.
3. Если Windows показывает синее окно SmartScreen, нажмите «Подробнее», затем «Выполнить в любом случае». Программа не подписана цифровой подписью, поэтому Windows предупреждает о ней.

## Как пользоваться

1. Запустите ShotFile. Значок появится в трее рядом с часами.
2. Нажмите **Win + Shift + S** и выделите область экрана.
3. Скриншот сохранится в выбранную папку, и появится уведомление.

Чтобы временно отключить сохранение, переведите переключатель в главном окне в положение «выкл» или выберите «Приостановить сохранение» в меню значка в трее. После перезапуска программа снова работает.

Закрытие окна программы не выключает её, она остаётся работать в трее. Чтобы выйти полностью, нажмите правой кнопкой на значок в трее и выберите «Выход».

## Настройки

Откройте окно программы и нажмите «Настройки» или выберите «Настройки» в меню значка в трее.

| Настройка | Что делает |
| --- | --- |
| Запускать вместе с Windows | Программа включается при входе в систему |
| Запускать свёрнутым в трей | Окно не показывается при запуске |
| Отслеживать Win + Shift + S | Сохраняются только скриншоты, сделанные этим сочетанием. Если выключить, сохраняется любая картинка, попавшая в буфер обмена |
| Режим работы | «Автоматически» сохраняет сразу, «Спрашивать» показывает окно с вопросом на 15 секунд |
| Игровой режим | В полноэкранной игре скриншоты сохраняются без окон и уведомлений, после игры показывается итог |
| Папка сохранения | Куда складываются файлы |
| Формат файлов | PNG (без потери качества) или JPG (меньше размер) |
| Шаблон имени файла | Как называются файлы |
| Уведомлять после сохранения | Показывать окно «Скриншот сохранён» |
| Сколько показывать | Через сколько секунд уведомление закрывается само (3, 6 или 10) |

### Шаблон имени файла

В шаблоне можно использовать:

| Запись | Значение |
| --- | --- |
| `yyyy` | год |
| `MM` | месяц |
| `dd` | день |
| `HH` | час |
| `mm` | минуты |
| `ss` | секунды |

Пример: `Screenshot_yyyy-MM-dd_HH-mm-ss` даст файл `Screenshot_2026-10-23_21-45-30.png`. Если файл с таким именем уже есть, к имени добавится номер.

Версия и номер сборки написаны внизу бокового меню настроек и на странице «О программе».

Настройки хранятся в `%APPDATA%\ShotFile\config.json`.

## Частые вопросы

**Скриншот не сохраняется.**
Проверьте, что программа запущена (значок в трее). Если Win + Shift + S не срабатывает, откройте настройки и выключите «Отслеживать сочетание клавиш Win + Shift + S». Так программа будет сохранять любую картинку из буфера обмена.

**Антивирус ругается на файл.**
Программа следит за сочетанием клавиш, и некоторые антивирусы относятся к этому настороженно. Добавьте `ShotFile.exe` в исключения или выключите отслеживание сочетания в настройках.

**Как убрать программу?**
Выключите «Запускать вместе с Windows» в настройках, выберите «Выход» в меню значка в трее и удалите `ShotFile.exe`. Папку `%APPDATA%\ShotFile` можно удалить вместе с настройками.

**Где мои скриншоты?**
Нажмите «Открыть папку» в меню значка в трее.

## Поддержать автора

ShotFile бесплатна. Если она вам пригодилась, можно отправить любую сумму в TON на кошелёк автора:

```
UQAbta5Av9SF3M4SlLTht530Ujth_SWotOpEx3A7cLCf8JxR
```

В программе есть кнопка «Поддержать автора»: она показывает этот адрес, копирует его и открывает кошелёк. Отправляйте только в сети TON (The Open Network).

## Сборка из исходного кода

Нужен Python 3.9 или новее.

```
pip install -r requirements.txt
python shotfile.py
```

Чтобы получить свой `ShotFile.exe`, запустите `build.bat`. Готовый файл появится в папке `dist`.
